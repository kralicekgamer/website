About Me

I'm Matěj Adamec, a developer from the Czech Republic known online as KralicekGamer or Kralyk.

Python is my main language. I use it to build REST APIs, TUI applications, automation scripts and system tools. I also know the basics of C#, and can work with HTML, CSS and JavaScript when a project needs a web interface.

My strongest interests are ethical hacking, cybersecurity and computer networking. I am passionate about Linux, open-source technologies and building reliable server infrastructure.

I have solid experience with Linux server administration, virtualization using Proxmox and partly VMware, and containerization with Docker.

I also work with Raspberry Pi, Arduino and ESP32, building hardware projects and experimenting with embedded systems.

Outside of technology, I enjoy walks, video games and music.
